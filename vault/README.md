# TruSoma Discourse Graphs vault (phase 1 of companion/DM_CONVERSION_PLAN_2026-11-15.md)
Authored source (phases 1 to 3) of the 171 learner values, the 928 body values and the 844 other values (Claims), their Evidence and the paper register (Sources), the method and join records (Claims), the audit log (Issues) and the remaining authored tables (Records, one row per note, in the property data). Everything else in the repository derived from them is generated by tools/dm/build_from_vault.py and checked in the pre-commit build step; never edit a generated file. Notes use frontmatter with one JSON value per line; titles "CLM - key", "EVD - key n", "@paper_id". Node ids are deterministic (tools/dm/dmlib.py). Obsidian workspace state (.obsidian/) is not committed.
Change a value: edit the Claim or Evidence note, run `python tools/dm/build_from_vault.py write` (writes every generated file: the two configurations, the links, register, audit log, records and tables), `python tools/dm/validate_vault.py`, then add the appendix [V] line and the code tag by hand as before (plan section 3c).
